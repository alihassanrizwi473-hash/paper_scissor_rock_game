A Python-based Rock Paper Scissors game that allows users to play the classic game using simple Python programming logic.

# Rock Paper Scissors Game 🎮

Rock Paper Scissors is a simple Python-based game where a user plays against the computer. The computer randomly selects Rock, Paper, or Scissors, and the winner is decided according to the game rules.

## Features
- Play against the computer.
- Random computer choices.
- User input handling.
- Automatic winner detection.
- Simple and interactive gameplay.

## Technologies Used
- Python
- Random Module

## Game Rules
- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both choices are the same, the result is a draw.

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python paper_scissor_rock_game.py
```

## Project Purpose
This project was created to practice Python programming concepts, including conditional statements, user input, randomization, and basic game logic.
